# Jeton

Les **Jetons** sont posés sur une [Carte](carte.md) du [Terrain](terrain.md) pour comptabiliser des valeurs qui lui sont relatives. Principaux types :

- **Jeton Quantité** : indique la quantité d'exemplaires de la carte (n-1, le premier exemplaire étant la carte elle-même). Voir [Jouer une carte](jouer-une-carte.md).
- **Jeton Branche** : indique le niveau de croissance d'une plante ou d'un bâtiment (ressource individuelle « branches », voir [Ressource](ressource.md)).

Pas encore implémenté. Sur les barrettes de ressources, des jetons servent déjà à suivre les valeurs (manuel).
