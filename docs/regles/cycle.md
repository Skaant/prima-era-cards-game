# Cycle

| N° | Clé | Description | Histoire |
|----|-----|-------------|----------|
| 1 | | Un cycle comporte trois phases dans cet ordre : pioche, pose de cartes et actions, production. | |
| 2 | | Le bouton « Nouveau cycle » termine le cycle en cours (phase de production) puis en démarre un (numéro +1, phase de pioche). | |
| 3 | | Au passage de cycle, les compteurs d'utilisation des actions de cartes (`fois`) sont remis à zéro. | |
| 4 | | Au passage de cycle, le compteur d'utilisations de l'action Piocher (payante) est remis à zéro. | |
