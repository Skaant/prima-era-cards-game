# Phase de production

| N° | Clé | Description | Histoire |
|----|-----|-------------|----------|
| 1 | | Chaque exemplaire du Terrain qui a un stock max de branches > 0 gagne 1 jeton Branche par cycle, dans la limite de son stock max. | |
| 2 | | L'énergie est remise à 0 à chaque phase de production (elle n'est pas conservée entre les cycles), avant l'ajout de la production. | |
| 3 | | Chaque ressource globale ajoute sa production par cycle à son stock, dans la limite du stock max. | |
| 4 | | La production par cycle d'une ressource est la somme des gains « par cycle » de tous les exemplaires du Terrain (chaque exemplaire compte séparément). | |
| 5 | | Un gain « par cycle » conditionné par un prérequis de branches (min / max / égal) n'est compté que si les branches de cet exemplaire respectent la condition. | |
| 6 | | Chaque zum (partie entière du total de zums) produit +1 data et +1 énergie par cycle. | |
| 7 | | Le total de zums compté pour cet effet est le stock global de zums, qui inclut déjà les zums associés aux exemplaires du Terrain (voir jouer-une-carte, règle 10). | |
| 8 | | Un gain « or » (choix) produit chaque cycle la ressource choisie parmi ses options ; par défaut la première option. | |
| 9 | | Le choix de la ressource d'un gain « or » se fait par exemplaire, peut être changé à tout moment, et prend effet à partir de la production suivante. | |
| 10 | | La production par cycle est recalculée après chaque carte jouée, action utilisée ou choix de ressource « or ». | |
