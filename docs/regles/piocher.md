# Piocher

| N° | Clé | Description | Histoire |
|----|-----|-------------|----------|
| 1 | | Piocher X (X est toujours un entier supérieur ou égal à 1) = prendre les X dernières cartes de la Pioche et les ajouter à la fin de la Main. | |
| 2 | | Si la Pioche contient moins de X cartes, toutes les cartes restantes sont piochées sans erreur. | |
| 3 | | Recyclage : quand la Pioche se vide en cours de pioche, la Défausse est mélangée et devient la nouvelle Pioche, puis on continue de piocher le nombre manquant. La Défausse devient vide. | |
| 4 | | Si la Pioche est vide et la Défausse aussi, la pioche s'arrête là (rien de plus n'est pioché). | |
| 5 | | Le hasard du jeu vient uniquement des mélanges (création de la Pioche, recyclage). | |
