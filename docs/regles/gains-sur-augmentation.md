# Gains sur augmentation

| N° | Clé | Description | Histoire |
|----|-----|-------------|----------|
| 1 | | Un gain `on` (une entrée de `gains.autres`) ne se produit pas à la pose de la carte, ni par cycle : il se produit uniquement quand la ressource `on.id` augmente (stock global, ou stock de branches de l'exemplaire pour `branches`). | |
| 2 | | Seule une augmentation réelle compte : un gain plafonné par le stock max ne compte que pour la part qui entre dans le stock. Toutes les sources d'augmentation comptent (gain de carte ou d'action, défausse, production de fin de cycle, autre gain `on`). | |
| 3 | | Chaque exemplaire compte les ressources gagnées jusqu'à atteindre `on.value` (1 par défaut) : à chaque tranche de `on.value` atteinte, le gain est obtenu une fois (une grosse augmentation peut donc le déclencher plusieurs fois), le reste est conservé pour la suite. | |
| 4 | | `on.fois` limite le nombre de déclenchements par cycle, par exemplaire et par gain ; avec `parRessource`, la limite est multipliée par le stock de cette ressource (divisé par `parRessource.value`, 1 par défaut). Les ressources gagnées au-delà de la limite sont perdues pour le compteur. Le nombre de déclenchements est remis à 0 au nouveau cycle. | |
| 5 | | Un gain `on` avec `activable` est actif à l'ajout de l'exemplaire ; le joueur peut le désactiver puis le réactiver, par exemplaire ou pour tous les exemplaires de la carte à la fois. Désactivé, il ne se déclenche pas et ne compte pas les ressources gagnées. | |
| 6 | | Un gain de `on.gain` portant son propre `prerequis` est vérifié au moment du déclenchement : non satisfait, seul ce gain-là n'a pas lieu. Les `prerequis` de `on.gain` n'affectent jamais le comptage commun du déclenchement `on` (compteur, `on.value`, `on.fois`) : celui-ci avance normalement même si un ou plusieurs gains de `on.gain` sont ignorés faute de `prerequis` satisfait. | |
| 7 | | Le gain d'un déclenchement est immédiat (stock plafonné au stock max, ou affinité de tribu) et peut lui-même faire augmenter une ressource et déclencher d'autres gains `on` (chaîne). La chaîne n'est jamais récursive : dès qu'un effet a été atteint dans la chaîne (qu'il ait été joué ou non : désactivé, `on.value` non atteint, limite `fois`), il n'est plus revu dans cette même chaîne (la ressource gagnée n'est alors pas comptée pour lui). | |
| 8 | | Un gain `on` peut déclencher plusieurs gains à la fois, via `on.gain` (qui reprend la forme d'un gain de carte : `tribus`, `ressources`, `autres`, sans pouvoir contenir de `on` imbriqué) : tous les gains de `on.gain` sont appliqués ensemble à chaque seuil atteint. Un gain `autres` de type `"or"` dans `on.gain` applique toujours sa première ressource (pas de choix du joueur pour ce cas). | |
