# Actions des cartes

| N° | Clé | Description | Histoire |
|----|-----|-------------|----------|
| 1 | | Une action de carte est une transformation de ressources proposée par les exemplaires d'une carte du Terrain, utilisable pendant la phase de pose de cartes et actions. | |
| 2 | | Utiliser une action : ses coûts (ressources globales) sont payés et ses gains immédiats sont récoltés (plafonnés au stock max). | |
| 3 | | Une action est impossible si un de ses coûts en ressource globale n'est pas couvert par le stock. | |
| 4 | | Une action peut être limitée à un nombre d'utilisations par cycle (`fois`) ; une fois la limite atteinte, elle est indisponible jusqu'au cycle suivant. | |
| 5 | | Le compteur d'utilisation d'une action est partagé par tous les exemplaires de la carte : une action disponible l'est pour tous les exemplaires, une action utilisée l'est pour tous. | |
| 6 | | Les coûts et gains « par cycle » ou « proportionnels » d'une action, son prérequis et une limite `fois` proportionnelle ne sont pas appliqués. *(spec, non implémenté)* | |
