# Phase de pioche

| N°  | Clé | Description                                                                                                                                                                                                                                 | Histoire |
| --- | --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| 1   |     | À chaque phase de pioche, le joueur pioche X `cartesParTour` (ressource globale) cartes, avec recyclage de la Défausse si besoin.                                                                                                           |          |
| 2   |     | « Cartes par tour » n'est pas une ressource stockée : c'est un nombre produit par les cartes du Terrain (gains « par cycle »), recalculé à chaque changement.                                                                               |          |
