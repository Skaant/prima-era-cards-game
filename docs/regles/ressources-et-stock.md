# Ressources et stock

| N° | Clé | Description | Histoire |
|----|-----|-------------|----------|
| 1 | | Ressources globales (un seul stock pour la partie) : eau, jing, data, zums, énergie. | |
| 2 | | Ressource individuelle : les branches, propres à chaque exemplaire de carte (représentées par des jetons Branche). | |
| 3 | | Le stock max initial de l'eau, du jing et des zums est 0 : sans carte qui l'augmente, ces ressources ne peuvent pas être stockées. | |
| 4 | | La data et l'énergie n'ont pas de stock max (illimitées). | |
| 5 | | Un gain ne peut jamais faire dépasser le stock max d'une ressource : l'excédent est perdu. | |
| 6 | | Les gains marqués « stock » augmentent le stock max (global, ou stock de branches de l'exemplaire joué) au lieu du stock. | |
| 7 | | Quand une carte donne à la fois un gain de stock max et un gain de stock, le stock max est augmenté en premier. | |
| 8 | | Les valeurs de production fractionnaires sont arrondies à 2 décimales. | |
| 9 | | Une action ou une carte sans stock de branches peut donner une branche (gain « or » avec choix de ressource, p. ex. Arroseureuse : Waild ou branche). Elle va dans un stock global invisible de branches en attente, qui n'apparaît pas dans la barre du haut ; ce stock ne se conserve pas : les branches qu'aucun exemplaire ne peut recevoir au moment de l'action sont perdues. Le choix de ressource se fait par bouton radio sur la carte (ou sur la ligne d'actions groupées) et s'applique à la prochaine utilisation de l'action. | |
| 10 | | Tant qu'une branche est en attente et qu'au moins un exemplaire du Terrain a un stock de branches non plein, un dialogue affiche ces exemplaires (pile, exemplaire current en entier). Cliquer le current lui ajoute une branche (retirée du stock en attente) ; cliquer un exemplaire masqué en fait le current sans ajouter de branche. Le dialogue se ferme quand plus aucune branche n'est en attente. | |
