# Actions de la Pioche et de la Défausse

| N° | Clé | Description | Histoire |
|----|-----|-------------|----------|
| 1 | | Action Piocher (payante) : le joueur peut à tout moment payer de la data pour piocher 1 carte. | |
| 2 | | Le coût de l'action Piocher est 1 + le nombre de fois où elle a déjà été utilisée ce cycle (1, puis 2, puis 3…). | |
| 3 | | L'action Piocher est impossible si Pioche et Défausse sont vides, ou si la data est inférieure au coût. | |
| 4 | | Action Défausser : le joueur choisit une carte de sa Main, elle va dans la Défausse et il gagne 1 data. | |
| 5 | | L'action Défausser est impossible sans carte choisie. | |
