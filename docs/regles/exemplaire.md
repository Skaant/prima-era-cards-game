# Exemplaire

| N° | Clé | Description | Histoire |
|----|-----|-------------|----------|
| 1 | | Jouer une carte ajoute un exemplaire de cette carte au Terrain. | |
| 2 | | Chaque exemplaire est indépendant : il a ses propres branches et son propre stock max de branches. | |
| 3 | | Cliquer sur un exemplaire le rend actif (affiché en entier), à son emplacement habituel dans la pile de sa carte, sans réordonner les exemplaires ; ce n'est qu'un effet d'affichage, sans conséquence sur les règles (production, actions…). | |
| 4 | | Chaque exemplaire masqué de la pile affiche une icône cliquable par action de la carte, grisée si l'action n'est pas utilisable, permettant de la jouer directement sans rendre l'exemplaire actif (affichage uniquement). | |
| 5 | | Une carte ayant un stock de branches n'affiche pas ce gain dans ses gains : à la place, juste au-dessus, une jauge affiche le libellé « x [icône branches] / y » (x la quantité de branches de l'exemplaire affiché en entier, y son stock max déclaré) suivie d'une ligne découpée en y rectangles, muted par défaut, noirs pour les x premiers ; dans la Main ou juste après avoir été jouée, x vaut 0. N'apparaît que sur les cartes ayant un tel gain. | |
