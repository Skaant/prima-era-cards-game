# Paquets d'évolution

| N° | Clé | Description | Histoire |
|----|-----|-------------|----------|
| 1 | | Quand le joueur choisit une carte parmi les cartes révélées d'un paquet d'évolution (achat), la carte est ajoutée à la fin de la Main, et non à la Pioche. La Pioche du joueur n'est pas mélangée à cette étape. | |
| 2 | | Les cartes révélées non choisies retournent dans la pile du paquet d'évolution, qui est remélangée. | |
